# freedo beta add-on

Runs the pre-releases of the freedo daemon, a local coordinator for tado 868 MHz heating devices, on
Home Assistant. A pre-release has less testing on a real plant than a stable release.

The add-on has its own data. To bring the plant of the stable freedo add-on here, download a backup
in its web interface and restore it in the web interface of this add-on. Stop the stable add-on
before you start this one: the two must not run at the same time. The add-on documentation
describes the move and the return to the stable add-on.
